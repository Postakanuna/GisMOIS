# Журнал изменений — ГИС МО «Инженерные сети»

Все значимые изменения в проекте документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
версионирование — по [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0-rc.1] — 2025-06-24

Первый релиз-кандидат системы, подготовленный для регистрации в Роспатенте.

### Добавлено
- Многосценовая архитектура с управлением рабочими пространствами (сценами)
- Интерактивная карта на базе OpenLayers с поддержкой WMS/WFS слоёв
- Подключение к ZuluGIS-серверу для получения данных инженерных сетей
- Панель управления слоями с настройкой видимости, прозрачности и стилей
- Расширенная стилизация: базовые фигуры, иконки по ГОСТ для тепловых сетей, пользовательские SVG
- Стилизация линий по ГОСТ для тепловых сетей
- Категоризированные и градуированные рендереры с настройкой стилей по классам
- Инструменты рисования и редактирования геометрий (точки, линии, полигоны)
- Атрибутивные таблицы с фильтрацией и поиском
- Импорт данных из Shapefile и XLSX
- Экспорт данных в GeoJSON и Shapefile
- Присоединение данных из Excel (Attribute Join)
- Геокодирование адресов (Яндекс Геокодер, DaData) с поддержкой ФИАС
- Автоматическое подключение потребителей к тепловой сети с расчётом параметров
- Анализ пропускной способности тепловых сетей
- AI-ассистент с RAG (OpenAI GPT-4o-mini, Yandex GPT-Lite)
- Ролевая модель доступа (администратор, оператор, наблюдатель)
- Управление API-ключами для внешнего доступа
- Аудит действий пользователей
- Система баг-репортов со скриншотами
- Тёмная и светлая тема интерфейса
- Координатный дисплей и инструменты измерения
- Кросс-сценовый поиск объектов
- Геопространственная аналитика
- Анализ жалоб с привязкой к объектам сети
- Валидация топологии сетей
- Администрирование слоёв с матричным представлением по сценам
- Депонированные материалы для регистрации в Роспатенте

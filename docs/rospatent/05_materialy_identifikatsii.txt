МАТЕРИАЛЫ, ИДЕНТИФИЦИРУЮЩИЕ ПРОГРАММУ ДЛЯ ЭВМ

Название программы:
  Государственная информационная система Московской области «Инженерные сети»
  (ГИС МО «ИС»)

Версия: 1.0.0-rc.1
Правообладатель: Министерство энергетики Московской области

Назначение документа:
  Настоящий документ содержит текстовые описания экранов (пользовательских
  интерфейсов) программы для ЭВМ, предназначенные для идентификации программы
  при государственной регистрации в Роспатенте.

  Место для скриншотов обозначено строкой [СКРИНШОТ]. Скриншоты вставляются
  правообладателем самостоятельно в порядке нумерации разделов.

============================================================================

ЭКРАН 1. ПОСАДОЧНАЯ СТРАНИЦА
Маршрут: /
Режим доступа: публичный (без авторизации)

Назначение:
  Первая публично доступная страница системы. Предоставляет общее описание
  ГИС МО «ИС» и обеспечивает точку входа для авторизованных пользователей.

Видимые элементы и их расположение:
  — Верхняя часть (шапка):
    • Логотип и название системы «ГИС МО ИС» (левый верхний угол)
    • Кнопка «Войти» (правый верхний угол), ведущая на страницу авторизации
  — Центральная секция (hero-блок):
    • Крупный заголовок с названием системы
    • Подзаголовок с описанием назначения платформы
    • Кнопка «Начать работу» / «Войти в систему»
  — Нижние секции (блоки возможностей):
    • Блок «Мониторинг и анализ сетей»: иконка + краткое описание
    • Блок «Работа с данными»: иконка + краткое описание
    • Блок «AI-ассистент»: иконка + краткое описание
    • Блок «Аналитика и отчёты»: иконка + краткое описание
  — Нижняя часть (футер):
    • Ссылка на внешний сервис ZuluWeb (инженерные расчёты)
    • Информация о правообладателе — Министерство энергетики МО

ЭКРАН 2. СТРАНИЦА АВТОРИЗАЦИИ
Маршрут: /gis/login
Режим доступа: публичный

Назначение:
  Экран входа в систему. Выполняет аутентификацию пользователя по логину и
  паролю. После успешного входа перенаправляет на страницу управления сценами.

Видимые элементы и их расположение:
  — Фон:
    • Тёмный градиентный фон, занимающий весь экран
  — Центральная карточка авторизации (по центру экрана):
    • Логотип системы и надпись «ГИС МО «Инженерные сети»» — вверху карточки
    • Поле «Логин» (текстовый ввод, обязательное)
    • Поле «Пароль» (ввод с маскировкой символов, кнопка показать/скрыть,
      обязательное)
    • Кнопка «Войти» (основная, на всю ширину карточки)
    • Сообщение об ошибке — под кнопкой (при неверных учётных данных)
  — Нижняя часть:
    • Ссылка «На главную» для возврата на посадочную страницу

ЭКРАН 3. УПРАВЛЕНИЕ СЦЕНАМИ (РАБОЧИМИ ПРОСТРАНСТВАМИ)
Маршрут: /gis/scenes
Режим доступа: авторизованные пользователи

Назначение:
  Страница выбора и управления рабочими пространствами (сценами). Каждая
  сцена — это независимое ГИС-окружение со своим набором слоёв, настройками
  и данными. Сцены организованы в папки.

Видимые элементы и их расположение:
  — Верхняя панель (шапка):
    • Логотип и название системы (слева)
    • Поисковая строка для фильтрации сцен по названию (по центру)
    • Имя текущего пользователя и кнопка «Выйти» (справа)
  — Рабочая область:
    • Дерево папок (панель слева, при наличии папок):
      - Корневая папка «Все сцены»
      - Пользовательские папки (иерархически)
    • Область карточек (основная часть экрана):
      - Карточки сцен — прямоугольные плитки с:
        · Названием сцены
        · Датой последнего изменения
        · Аватаром последнего редактора
        · Иконкой меню (три точки) в правом верхнем углу карточки
      - Карточки папок — аналогичные плитки с иконкой папки
  — Контекстное меню карточки (по нажатию «...»):
    • «Открыть» — переходит к карте сцены
    • «Переименовать» — встроенное поле редактирования
    • «Переместить» — диалог выбора целевой папки
    • «Управление доступом» — диалог назначения прав (только для администратора)
    • «Удалить» — подтверждение удаления
  — Кнопки создания (правый нижний угол или верхняя панель):
    • «+ Новая сцена»
    • «+ Новая папка»

ЭКРАН 4. ГЛАВНАЯ РАБОЧАЯ СТРАНИЦА — КАРТА
Маршрут: /gis/app
Режим доступа: авторизованные пользователи

Назначение:
  Основной рабочий экран системы. Содержит интерактивную карту инженерных
  сетей и полный набор инструментов для просмотра, редактирования, анализа
  данных и работы с AI-ассистентом.

Видимые элементы и их расположение:

  4.1. Интерактивная карта (центр экрана, занимает большую часть):
    • Картографическая подложка OpenStreetMap (тёмная/светлая тема)
    • WMS-слои инженерных сетей из ZuluGIS (тепло-, водо-, газо-, электросети)
    • Векторные редактируемые слои (трубопроводы, узлы, потребители)
    • Выделенные объекты подсвечиваются при клике
    • Тематическая окраска объектов по типу сети (красный — теплоснабжение,
      синий — водоснабжение, жёлтый — газоснабжение, оранжевый — электросети)

  4.2. Левая боковая панель (вертикальная, фиксированная):
    • Кнопка-переключатель «Слои» (иконка стопка слоёв)
    • Кнопка-переключатель «Объект» (иконка информация) — информация
      о выбранном объекте
    • Кнопка-переключатель «AI» (иконка чат/нейросеть) — AI-ассистент
    • Кнопка «Профиль» (иконка пользователя, внизу панели)
    • Кнопка «Выйти» (иконка выхода, внизу панели)

  4.3. Панель слоёв (раскрывается из левой боковой панели):
    • Название текущей сцены — вверху панели
    • Кнопка «Добавить слой» / «Импорт данных»
    • Список слоёв, каждый элемент содержит:
      - Переключатель видимости (глаз)
      - Цветной индикатор стиля слоя
      - Название слоя
      - Ползунок прозрачности (0–100%)
      - Кнопка «Стиль» (иконка кисти)
      - Кнопка «Атрибуты» (иконка таблицы)
      - Кнопка «Фокус» (приближение к содержимому слоя)
    • Кнопка «Менеджер данных» (импорт Shapefile/Excel) — внизу панели

  4.4. Панель инструментов рисования (горизонтальная, по центру сверху):
    Группа «Режимы выбора и рисования»:
      • Стрелка (выбор объектов)
      • Точка (добавление точечного объекта)
      • Линия (добавление линейного объекта)
      • Полигон (добавление площадного объекта)
      • Редактирование вершин выбранного объекта
    Разделитель
    Группа «Операции с данными»:
      • Атрибутивная таблица активного слоя
      • Привязка (snap) — включение/выключение магнитной привязки
      • Присоединение данных из Excel (Attribute Join)
    Разделитель
    Группа «Аналитические инструменты»:
      • Трассировка сети (найти путь от объекта до источника)
      • Симуляция отключения (моделирование аварийного сценария)
      • Подключение потребителя (автоматический расчёт подключения)
      • Валидация топологии (проверка связности сети)
      • Геопространственный анализ (буфер, пересечение, объединение)
    Разделитель
    Группа «Операции редактирования»:
      • Удалить выбранный объект
      • Отменить (Undo)
      • Повторить (Redo)
      • Сохранить изменения (отправка на сервер)

  4.5. Панель управления картой (правый верхний угол, вертикальная):
    • Кнопка «+» (приблизить)
    • Кнопка «–» (отдалить)
    • Кнопка «↺» (сбросить угол поворота карты)
    • Кнопка домик/дом (начальный вид / исходный экстент)
    • Кнопка полный экран (развернуть карту на весь экран)
    • Кнопка обновления (↻) — принудительный сброс кэша геометрии и перезагрузка
      данных карты (вращается 1,5 сек при выполнении)
    • Линейка (измерение расстояний на карте)

  4.6. Строка статуса (нижняя часть карты):
    • Текущие географические координаты курсора (широта / долгота)
    • Текущий масштаб карты (знаменатель)
    • Информация о точности дискретизации координат

ЭКРАН 5. АТРИБУТИВНАЯ ТАБЛИЦА СЛОЯ
Открывается из: Панель слоёв → кнопка «Атрибуты» / Панель инструментов →
  «Атрибутивная таблица»
Режим доступа: авторизованные пользователи

Назначение:
  Табличный просмотр и редактирование всех объектов (features) активного слоя.
  Обеспечивает массовый просмотр, фильтрацию, сортировку и выборку объектов.

Видимые элементы и их расположение:
  — Панель управления таблицей (верхняя полоса):
    • Название слоя
    • Строка поиска / фильтрации по значению атрибута
    • Кнопка «Экспорт» (выгрузка в CSV или Excel)
    • Счётчик: «Показано X из Y объектов»
    • Кнопка закрытия таблицы
  — Основная таблица:
    • Заголовки столбцов с именами атрибутивных полей
      (нажатие на заголовок — сортировка по возрастанию/убыванию)
    • Строки объектов:
      - Чекбокс выбора (первый столбец)
      - Значения атрибутов (текст, числа, даты)
      - Кнопка «Перейти» (наведение камеры на объект на карте)
    • Горизонтальная прокрутка при большом количестве полей
    • Вертикальная прокрутка при большом количестве объектов
  — Нижняя строка:
    • Количество выбранных строк
    • Кнопка «Выбрать всё» / «Снять выбор»

ЭКРАН 6. ИНФОРМАЦИЯ ОБ ОБЪЕКТЕ (ПАНЕЛЬ)
Открывается из: клик по объекту на карте + выбор вкладки «Объект»
Режим доступа: авторизованные пользователи

Назначение:
  Боковая панель с детальными атрибутами одного выбранного пространственного
  объекта. Поддерживает просмотр и редактирование атрибутов.

Видимые элементы и их расположение:
  — Заголовок панели:
    • Название слоя, к которому принадлежит объект
    • Идентификатор объекта (ID)
    • Кнопка закрытия панели
  — Список атрибутов (основная часть):
    • Пары «Имя поля — Значение» (двухколоночный список)
    • Поля с единицами измерения (диаметры в мм, длина в м)
    • Специальные поля: тип сети, система, начало/конец участка
  — Нижняя панель действий:
    • Кнопка «Редактировать» (переход в режим редактирования атрибутов)
    • Кнопка «Удалить объект» (с подтверждением)
    • Кнопка «Центрировать» (фокус карты на объекте)

ЭКРАН 7. ИНСТРУМЕНТ «ТРАССИРОВКА МАРШРУТА»
Открывается из: Панель инструментов → кнопка «Трассировка» → клик по объекту
Режим доступа: авторизованные пользователи

Назначение:
  Вычисление и визуализация пути по тепловой или водопроводной сети от
  выбранного объекта (потребителя / участка трубопровода) до источника
  ресурса (котельная, ЦТП, ВНС и др.).

Видимые элементы и их расположение:
  — Диалоговое окно (по центру или закреплено справа):
    • Заголовок «Трассировка маршрута»
    • Поле «Начальный объект»: наименование выбранного объекта,
      координаты или ID
    • Кнопка «Найти маршрут» (запуск алгоритма обхода графа)
    • Секция результатов:
      - Найден источник: название и тип
      - Длина маршрута (м)
      - Количество узлов по пути
      - Список промежуточных объектов (камеры, тепловые пункты)
    • Кнопка «Очистить маршрут»
    • Кнопка «Закрыть»
  — На карте при активной трассировке:
    • Подсветка трассированных участков трубопровода
      (цветная линия поверх основного слоя)
    • Маркеры узлов по маршруту
    • Маркер источника (котельной / ЦТП)

ЭКРАН 8. ИНСТРУМЕНТ «СИМУЛЯЦИЯ ОТКЛЮЧЕНИЯ СЕТИ»
Открывается из: Панель инструментов → кнопка «Симуляция» → клик по объекту
Режим доступа: авторизованные пользователи

Назначение:
  Моделирование аварийного сценария отключения участка сети. Определяет, какие
  потребители остаются без ресурса при отключении выбранного элемента
  (трубопровод, задвижка, узел).

Видимые элементы и их расположение:
  — Диалоговое окно:
    • Заголовок «Симуляция отключения»
    • Информация об отключаемом объекте:
      - Тип объекта (участок трубопровода / задвижка / ТК)
      - Название / идентификатор
      - Система (теплоснабжение / ГВС / водоснабжение)
    • Кнопка «Запустить симуляцию»
    • Секция результатов:
      - Количество отключённых потребителей
      - Количество отключённых участков сети
      - Таблица отключённых объектов: тип, адрес/название
    • Кнопка «Экспорт результатов» (Excel/CSV)
    • Кнопка «Очистить симуляцию»
    • Кнопка «Закрыть»
  — На карте при активной симуляции:
    • Зона отключения выделена полупрозрачным цветовым оверлеем
    • Отключённые участки трубопровода окрашены в серый
    • Отключённые потребители помечены специальным маркером

ЭКРАН 9. ИНСТРУМЕНТ «АНАЛИЗ АВАРИЙНОСТИ»
Открывается из: AI-ассистент (маркер [ACTION:ACCIDENT_ANALYSIS:...]) или
  меню аналитических инструментов
Режим доступа: авторизованные пользователи

Назначение:
  Анализ аварийности трубопроводной сети. Выполняет пространственное
  связывание событий аварий (из слоя аварий) с участками трубопроводов
  в радиусе до 15 м. Ранжирует участки по количеству аварий и формирует
  аналитические отчёты.

Видимые элементы и их расположение:
  — Диалоговое окно:
    • Заголовок «Анализ аварийности трубопроводов»
    • Секция настроек (верхняя часть):
      - Выпадающий список «Слой аварий» (выбор источника данных об авариях)
      - Выпадающий список «Слой трубопроводов» (выбор анализируемой сети)
      - Поле «Радиус привязки» (м, по умолчанию 15)
      - Кнопка «Запустить анализ»
    • Секция результатов (после выполнения анализа):
      - Итоговая строка: «Проанализировано аварий: N, связано с участками: M»
      - Таблица результатов со столбцами:
        · №
        · Система (ТС / ГВС)
        · Начало участка (Begin_uch)
        · Конец участка (End_uch)
        · Д подачи (мм)
        · Д обратки (мм)
        · Длина (м)
        · Кол-во аварий
      - Строки отсортированы по убыванию количества аварий
    • Нижняя панель действий:
      - Кнопка «Экспорт в Excel» (выгрузка полной таблицы)
      - Кнопка «Сохранить в слой» (выпадающий список целевого слоя,
        сохраняет буферные полигоны 5 м вокруг аварийных участков
        с атрибутами анализа)
      - Кнопка «Закрыть»

[СКРИНШОТ 9 — Инструмент анализа аварийности]

============================================================================

ЭКРАН 10. ИНСТРУМЕНТ «АНАЛИЗ ЖАЛОБ»
Открывается из: AI-ассистент или меню аналитических инструментов
Режим доступа: авторизованные пользователи

Назначение:
  Пространственный анализ обращений и жалоб граждан на проблемы
  с инженерными сетями. Кластеризует жалобы по географии, определяет
  проблемные зоны и оценивает вероятность инфраструктурной причины.

Видимые элементы и их расположение:
  — Диалоговое окно:
    • Заголовок «Анализ жалоб и обращений»
    • Секция настроек:
      - Многоселект «Слои жалоб» (выбор до 5 слоёв с данными)
      - Выпадающий список «Поле даты» (для временной фильтрации)
      - Выпадающий список «Поле адреса»
      - Поле «Радиус кластеризации» (м)
      - Переключатель «Учитывать период» с диапазоном дат (от — до)
      - Кнопка «Запустить анализ»
    • Секция результатов:
      - Карта с цветовыми маркерами кластеров
        (размер маркера пропорционален количеству жалоб)
      - Таблица кластеров:
        · Адрес / район
        · Количество жалоб
        · Количество затронутых потребителей (расчётное)
        · Вероятность инфраструктурной причины (%)
        · Рекомендуемое действие
    • Кнопка «Экспорт» (Excel/CSV)
    • Кнопка «Закрыть»

ЭКРАН 11. ИНСТРУМЕНТ «АВТОМАТИЧЕСКОЕ ПОДКЛЮЧЕНИЕ ПОТРЕБИТЕЛЯ»
Открывается из: Панель инструментов → кнопка «Подключение потребителя»
Режим доступа: авторизованные пользователи

Назначение:
  Автоматизированный расчёт и оформление подключения нового потребителя
  к тепловой сети. Определяет оптимальную трассу, тип и параметры
  трубопровода, оценивает пропускную способность существующей инфраструктуры.

Видимые элементы и их расположение:
  — Диалоговое окно (многошаговое):
    • Заголовок «Подключение потребителя»
    Шаг 1 — Параметры объекта:
      - Поле «Наименование объекта»
      - Поле «Адрес»
      - Выпадающий список «Тип здания»
        (жилой дом, административное, промышленное и т.д.)
      - Поля тепловых нагрузок:
        · Нагрузка на отопление (Гкал/ч)
        · Нагрузка на ГВС (Гкал/ч)
        · Нагрузка на вентиляцию (Гкал/ч)
      - Кнопка «Рассчитать подключение»
    Шаг 2 — Результаты анализа (после расчёта):
      - Ближайшая точка подключения к сети (ТК / тепловая камера)
      - Рекомендуемые параметры трубопровода:
        · Диаметр подачи (мм)
        · Диаметр обратки (мм)
        · Длина трассы (м)
      - Пропускная способность ближайшего ЦТП/источника:
        · Текущая нагрузка (Гкал/ч)
        · Свободная мощность (Гкал/ч)
        · Достаточность мощности (да / нет, с цветовым индикатором)
      - Трасса маршрута подключения на карте (синяя пунктирная линия)
      - Кнопка «Добавить в слой» (создание нового участка трубопровода)
      - Кнопка «Экспорт ТУ» (технические условия в Excel)
    • Кнопка «Закрыть»

ЭКРАН 12. AI-АССИСТЕНТ (ПАНЕЛЬ ЧАТА)
Открывается из: Левая боковая панель → кнопка «AI»
Режим доступа: авторизованные пользователи

Назначение:
  Встроенный AI-ассистент на базе больших языковых моделей с RAG-обогащением
  контекстом текущей сцены. Отвечает на вопросы о данных инженерных сетей
  и запускает аналитические инструменты по текстовой команде.

Видимые элементы и их расположение:
  — Боковая панель (раздвижная, справа или слева):
    • Заголовок «AI-ассистент»
    • Кнопка выбора провайдера LLM (если настроено несколько)
    • Область истории диалога (прокручиваемая):
      - Сообщения пользователя (выровнены справа, другой цвет фона)
      - Сообщения ассистента (выровнены слева):
        · Текстовый ответ
        · Кнопки действий (интерактивные, при наличии рекомендаций):
          например «Запустить анализ аварийности»,
          «Показать на карте», «Экспортировать результаты»
        · Блоки с таблицами данных (при аналитических ответах)
    • Индикатор загрузки (три точки, анимация) — пока ассистент отвечает
    • Нижняя секция ввода:
      - Текстовое поле «Задайте вопрос...» (многострочное)
      - Кнопка «Отправить» (иконка отправки)
      - Кнопка «Очистить историю»

ЭКРАН 13. МЕНЕДЖЕР ДАННЫХ (ИМПОРТ)
Открывается из: Панель слоёв → кнопка «Менеджер данных» / «Импорт»
Режим доступа: авторизованные пользователи

Назначение:
  Диалоговое окно для загрузки и импорта внешних данных в слои системы.
  Поддерживает форматы Shapefile (в ZIP-архиве) и Excel (XLSX).

Видимые элементы и их расположение:
  — Диалоговое окно с вкладками:
    Вкладка «Shapefile / ZIP»:
      - Область перетаскивания файла (Drag & Drop) или кнопка «Выбрать файл»
      - Поддерживаемые форматы: .zip содержащий .shp, .dbf, .shx, .prj
      - Выпадающий список «Целевой слой» (куда импортировать)
      - Выпадающий список «Система координат» (EPSG:4326, EPSG:32637, и др.)
      - Чекбокс «Перепроецировать в WGS84»
      - Кнопка «Импортировать»
    Вкладка «Excel (XLSX)»:
      - Область загрузки Excel-файла
      - Настройка маппинга колонок:
        · Выпадающий список «Колонка X (долгота)»
        · Выпадающий список «Колонка Y (широта)»
      - Предпросмотр первых строк файла (таблица)
      - Выпадающий список «Целевой слой»
      - Кнопка «Импортировать»
  — Прогресс-бар (отображается при фоновой обработке):
    • Анимированная полоса прогресса
    • Текст статуса: «Обработка... X из Y объектов»
  — Кнопка «Закрыть» (доступна всегда)

ЭКРАН 15. ПАНЕЛЬ АДМИНИСТРАТОРА
Маршрут: /gis/admin
Режим доступа: пользователи с ролью «Администратор»

Назначение:
  Административный интерфейс для управления пользователями, конфигурирования
  внешних сервисов, просмотра аудиторских журналов и обработки обращений.

Видимые элементы и их расположение:
  — Верхняя панель навигации:
    • Логотип и название системы (слева)
    • Имя администратора и кнопка «Выйти» (справа)
    • Кнопка «К карте» / «К сценам»
  — Горизонтальные вкладки (основная навигация):

    15.1. Вкладка «Пользователи»:
      • Кнопка «Добавить пользователя» (правый верхний угол вкладки)
      • Таблица пользователей:
        - Столбцы: ФИО, Логин, Роль, Организация, Статус (активен/заблокирован)
        - Кнопки действий в строке: Редактировать, Смена пароля, Удалить
      • Диалог добавления/редактирования пользователя:
        - Поля: ФИО, Логин, Email, Должность, Организация, Роль, Пароль
        - Кнопки: Сохранить, Отмена

    15.2. Вкладка «Аудит»:
      • Фильтры (верхняя строка):
        - Выбор пользователя (выпадающий список)
        - Тип действия (выпадающий список)
        - Диапазон дат (от — до)
        - Кнопка «Применить фильтр»
      • Таблица журнала:
        - Столбцы: Дата/Время, Пользователь, Действие, Объект, Подробности

    15.3. Вкладка «Геокодирование»:
      • Список провайдеров геокодирования (Яндекс.Карты, DaData, Google Maps)
      • Для каждого провайдера:
        - Переключатель активности
        - Поле API-ключа (маскируется, кнопка показать/скрыть)
        - Кнопка «Проверить» (тест подключения)
        - Кнопка «Сохранить»

    15.4. Вкладка «AI-агент»:
      • Глобальный переключатель «AI-ассистент включён» (в правом верхнем углу)
      • Список провайдеров LLM:
        - Карточка провайдера: название, URL, модель, статус
        - Кнопки: Редактировать, Удалить, Тест подключения
      • Кнопка «Добавить провайдера»
      • Диалог добавления/редактирования:
        - Поля: Название, URL API, Название модели, API-ключ
        - Кнопки: Сохранить, Отмена

    15.5. Вкладка «API-ключи»:
      • Таблица внешних API-ключей:
        - Столбцы: Название, Ключ (маскирован), Права, Дата создания
        - Кнопки: Скопировать, Отозвать
      • Кнопка «Сгенерировать новый ключ»

    15.6. Вкладка «Ошибки» (баг-репорты):
      • Таблица обращений пользователей:
        - Столбцы: Дата, Пользователь, Статус, Краткое описание
        - Строка раскрывается для просмотра полного описания и вложенных
          скриншотов (если пользователь их приложил)
      • Кнопки изменения статуса: «В работе», «Решено», «Отклонено»

ЭКРАН 16. МЕНЕДЖЕР СЛОЁВ (АДМИНИСТРАТОР)
Маршрут: /gis/admin/layers
Режим доступа: пользователи с ролью «Администратор»

Назначение:
  Административный инструмент управления составом слоёв в разрезе всех сцен
  системы. Позволяет назначать слои на сцены, массово клонировать и
  настраивать стили и типы сетей.

Видимые элементы и их расположение:
  — Верхняя панель:
    • Заголовок «Менеджер слоёв»
    • Кнопка «Создать слой» (добавление нового глобального слоя)
    • Кнопка «Клонировать выбранные» (массовая операция)
    • Строка поиска слоёв
  — Матричная таблица (основная область):
    • Строки = слои системы (название, тип сети, цветовой индикатор)
    • Столбцы = сцены (названия сцен в заголовках столбцов)
    • Ячейки на пересечении — переключатель (включён/выключен):
      - Включён (зелёная галочка): слой доступен в данной сцене
      - Выключен (серый): слой не подключён к данной сцене
    • Строка «Итого» в последнем столбце: количество сцен, к которым
      подключён данный слой
  — Боковая панель настроек слоя (раскрывается при выборе строки):
    • Название слоя (редактируемое)
    • Тип сети (выпадающий список: тепло, вода, газ, электро, общий)
    • Цвет (выбор из палитры)
    • Тип геометрии (точка / линия / полигон)
    • Источник данных (редактируемый слой / WMS / WFS)
    • Кнопки «Сохранить», «Удалить слой»

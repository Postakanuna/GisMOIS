# Список внешних сетевых адресов ГИС МО «Инженерные сети»

Документ содержит перечень внешних доменов и IP-адресов, к которым обращается система.
Используется для настройки белого списка (whitelist) на фаерволе продакшн-сервера.

## Пояснения

### 1. Картографические подложки (тайлы)

**OpenStreetMap** — основная подложка карты. Библиотека OpenLayers обращается к серверам тайлов OSM через поддомены `a`, `b`, `c` для балансировки нагрузки. Без доступа к этим адресам карта будет отображаться без фоновой подложки.

**Яндекс Карты / Спутник** — альтернативные подложки. Используются, если пользователь переключает тип карты. Если доступ не нужен, можно не добавлять в whitelist — система продолжит работать на подложке OSM.

### 2. Геокодирование

Система поддерживает три провайдера геокодирования. Достаточно открыть доступ хотя бы к одному из них:

- **Яндекс Геокодер** (`geocode-maps.yandex.ru`) — требует API-ключ в переменной `YANDEX_GEOCODER_API_KEY`
- **DaData** (`suggestions.dadata.ru`) — требует API-ключ в переменной `DADATA_API_KEY`, предоставляет коды ФИАС
- **Nominatim** (`nominatim.openstreetmap.org`) — бесплатный, без ключа, ограничения по частоте запросов

Если ни один геокодер недоступен, функции поиска адресов и обратного геокодирования будут отключены, но остальная система продолжит работать.

### 3. Маршрутизация (OSRM)

**OSRM** (`router.project-osrm.org`) — используется для построения маршрутов вдоль дорог при авто-трассировке теплосетей и автоматическом подключении потребителей. Без доступа функции авто-трассировки и автоподключения потребителей не будут работать.

*\* Обязателен только при использовании функций авто-трассировки и автоподключения потребителей.*

### 4. AI-провайдеры

Адрес AI-провайдера **настраивается администратором** через панель управления (таблица `ai_providers` в БД). По умолчанию используется OpenAI (`api.openai.com`), но администратор может указать любой OpenAI-совместимый эндпоинт:

- **OpenAI** — `api.openai.com`
- **Локальный LMStudio** — например, `http://192.168.x.x:1234/v1`
- **Ollama** — например, `http://localhost:11434/v1`
- **Другие** — любой OpenAI-совместимый API

Если AI-провайдер размещён в локальной сети, внешний доступ не требуется.

*\*\* Обязателен только при использовании AI-расчётов в авто-трассировке и AI-ассистента. При отключённом AI-агенте используется эвристический расчёт параметров.*

### 5. ZuluServer (ZWS)

Подключение к ZuluServer для получения слоёв WMS/WFS. Адрес настраивается через интерфейс подключения. По умолчанию — `is.arki.mosreg.ru/zws`.

*\*\*\* Если ZuluServer развёрнут на том же сервере или в той же локальной сети, внешний доступ не требуется.*

## Порты и протоколы

Все внешние сервисы используют **HTTPS (порт 443)**. Исключение — если ZuluServer или AI-провайдер настроен на HTTP-адрес в локальной сети.

Для корректной работы на фаерволе необходимо разрешить **исходящие TCP-соединения на порт 443** для перечисленных доменов.

# Инструкция по развёртыванию ГИС МО "Инженерные сети" на локальном компьютере

## Требования к системе

- Windows 10/11 (64-bit)
- Минимум 4 ГБ оперативной памяти
- 2 ГБ свободного места на диске

---

## Шаг 1: Установка необходимого ПО

### 1.1 Node.js (версия 20 или выше)

1. Перейдите на https://nodejs.org/
2. Скачайте **LTS версию** (зелёная кнопка)
3. Запустите установщик, нажимайте "Next" до конца
4. После установки перезагрузите компьютер

**Проверка:** откройте командную строку (Win+R → `cmd`) и введите:
```
node --version
```
Должно показать `v20.x.x` или выше.

### 1.2 PostgreSQL (база данных)

1. Перейдите на https://www.postgresql.org/download/windows/
2. Нажмите "Download the installer"
3. Скачайте последнюю версию (например 16.x)
4. Запустите установщик:
   - Выберите путь установки (можно оставить по умолчанию)
   - **Запомните пароль для пользователя postgres** — он понадобится!
   - Порт оставьте 5432 (по умолчанию)
   - Локаль: Russian, Russia
5. Завершите установку

### 1.3 Git (для скачивания кода)

1. Перейдите на https://git-scm.com/download/win
2. Скачайте и установите (все настройки по умолчанию)

---

## Шаг 2: Скачивание проекта

Откройте командную строку (Win+R → `cmd`) и выполните:

```bash
cd C:\
git clone https://github.com/ВАШ_РЕПОЗИТОРИЙ/gis-mo.git
cd gis-mo
```

Если репозиторий приватный или у вас нет Git, можно:
1. Скачать ZIP-архив проекта
2. Распаковать в папку `C:\gis-mo`
3. Открыть командную строку в этой папке

---

## Шаг 3: Создание базы данных

### 3.1 Откройте pgAdmin 4 
(устанавливается вместе с PostgreSQL, найдите в меню Пуск)

### 3.2 Создайте базу данных:
1. В левой панели раскройте "Servers" → "PostgreSQL 16"
2. Введите пароль от postgres (который задали при установке)
3. Правой кнопкой на "Databases" → "Create" → "Database"
4. Имя базы: `gismo`
5. Нажмите "Save"

### 3.3 Выполните SQL-скрипт:
1. Правой кнопкой на базу `gismo` → "Query Tool"
2. Откройте файл `C:\gis-mo\migrations\init.sql` (File → Open)
3. Нажмите кнопку "Execute" (▶) или F5
4. Должно появиться сообщение об успешном выполнении

---

## Шаг 4: Настройка переменных окружения

В папке `C:\gis-mo` создайте файл `.env` с содержимым:

```
DATABASE_URL=postgresql://postgres:ВАШ_ПАРОЛЬ@localhost:5432/gismo
SESSION_SECRET=любая_длинная_случайная_строка_минимум_32_символа
NODE_ENV=development
PORT=5000
```

**Замените:**
- `ВАШ_ПАРОЛЬ` — пароль от PostgreSQL, который задали при установке
- `SESSION_SECRET` — любая случайная строка (можно сгенерировать на https://randomkeygen.com/)

---

## Шаг 5: Установка зависимостей и запуск

Откройте командную строку в папке проекта:

```bash
cd C:\gis-mo

# Установка зависимостей (занимает 2-5 минут)
npm install

# Синхронизация схемы базы данных
npm run db:push

# Создание первого администратора
npx tsx scripts/init-admin.ts -- --username=admin --password=ВашПароль123

# Запуск приложения
npm run dev
```

---

## Шаг 6: Проверка работы

1. Откройте браузер
2. Перейдите на http://localhost:5000
3. Войдите с логином `admin` и паролем, который указали при создании

## Возможные проблемы и решения

### "npm не является внутренней командой"
- Перезагрузите компьютер после установки Node.js
- Или добавьте путь к Node.js в переменную PATH

### "Ошибка подключения к базе данных"
- Проверьте, что PostgreSQL запущен (в диспетчере служб Windows)
- Проверьте правильность пароля в файле `.env`
- Убедитесь, что база `gismo` создана

### "Порт 5000 занят"
- Измените порт в файле `.env` на другой (например 3000)
- Или найдите и остановите процесс, занимающий порт 5000

### "Ошибка при npm install"
- Удалите папку `node_modules` и файл `package-lock.json`
- Запустите `npm install` заново

## Запуск через Docker (альтернативный способ)

Если на компьютере установлен Docker Desktop:

```bash
cd C:\gis-mo

# Создать файл переменных
echo SESSION_SECRET=ваша_случайная_строка_32_символа > .env

# Запустить приложение и базу данных
docker-compose up -d

# Создать администратора
docker-compose exec app npx tsx scripts/init-admin.ts -- --username=admin --password=ВашПароль123
```

Приложение будет доступно по адресу http://localhost:5000
